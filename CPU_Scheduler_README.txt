   CPU SCHEDULING SIMULATOR (AppImage Edition)
───────────────────────────────────────────────

📘 ABOUT
────────
CPU Scheduling Simulator is a graphical Linux application
developed in C using GTK3 and Cairo. It visually demonstrates
various CPU scheduling algorithms used in Operating Systems
Fundamentals (OSF), including:

  • First-Come, First-Served (FCFS)
  • Shortest Job First (Non-preemptive)
  • Priority Scheduling (Non-preemptive)
  • Round Robin
  • Shortest Remaining Time First (Preemptive SJF)
  • Preemptive Priority Scheduling

This tool allows users to adjust process parameters such as
Arrival Time, Burst Time, and Priority, and then visualize
how each algorithm executes using a colorful animated
Gantt chart.

💻 SYSTEM REQUIREMENTS
──────────────────────
• Linux (any modern distro: Arch, Ubuntu, Fedora, Manjaro)
• GTK 3.x runtime (usually pre-installed)
• No installation required — portable AppImage format

───────────────────────────────────────────────
🚀 HOW TO RUN
─────────────
1. Save the file:
     CPU_Scheduling_Simulator-x86_64.AppImage

2. Make it executable:
     chmod +x CPU_Scheduling_Simulator-x86_64.AppImage

3. Run it:
     ./CPU_Scheduling_Simulator-x86_64.AppImage

4. The application window will open, showing:
   - Algorithm dropdown
   - Process entry grid
   - Run Simulation button
   - Animated Gantt Chart
   - “About” button for details
